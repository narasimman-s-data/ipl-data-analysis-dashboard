# 🏏 IPL Data Analysis Dashboard (2008–2025)

## 📌 Project Overview

This project presents an interactive dashboard analyzing the Indian Premier League (IPL) from 2008 to 2025. It explores team performance, player statistics, match results, and historical trends to uncover meaningful insights from IPL data.

## 🎯 Business Objective

To analyze IPL match and ball-by-ball data to identify top-performing players, successful teams, batting and bowling trends, and match-winning patterns, enabling data-driven insights into IPL performance.

## 📂 Datasets Used

The project uses the following datasets:

- `ball_by_ball_data.csv` — Ball-by-ball match information and player performance.
- `ipl_matches_data.csv` — Match details, results, venues, and season information.
- `players-data-updated.csv` — Player information and related attributes.
- `teams_data.csv` — Team details and identifiers.

## 🛠️ Tools & Technologies

- **Power BI** — Interactive dashboard development and visualization.
- **CSV** — Data source files.
- **Data Analytics** — Performance analysis, comparisons, and trend identification.

## 📊 Key Analysis Areas

- Season-wise IPL performance analysis.
- Team wins and match result comparisons.
- Top-performing batsmen and bowlers.
- Batting and bowling performance trends.
- Player performance comparisons.
- Match outcomes and venue-based insights.
- Historical IPL trends from 2008 to 2025.

## 📈 Dashboard Features

- Interactive visualizations and filters.
- Team and player performance comparisons.
- Season-wise trend analysis.
- Key performance indicators (KPIs).
- Historical match data exploration.

## 💡 Business Insights

The dashboard helps explore questions such as:

- Which teams have performed best across IPL seasons?
- Which players have delivered outstanding batting and bowling performances?
- How have team performances changed over time?
- What patterns can be observed in match results?
- Which venues and seasons show notable performance trends?

## 🚀 How to Use

1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `IPL Dashboard.pbix` file.
4. If required, update the dataset file paths in Power BI.
5. Refresh the data and explore the interactive dashboard.

This project demonstrates the use of data visualization and analytical techniques to explore IPL history, compare team and player performances, and communicate cricket insights through an interactive Power BI dashboard.
